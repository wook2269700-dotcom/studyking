# 강준영·강채영 학습왕 (Android Studio 프로젝트)

## 빌드 방법
1. Android Studio 최신 안정 버전을 설치합니다.
2. 이 폴더를 Android Studio에서 `Open`으로 엽니다.
3. Gradle Sync가 끝나면 `Build > Build Bundle(s) / APK(s) > Build APK(s)`를 선택합니다.
4. 생성된 APK를 갤럭시 휴대폰으로 옮겨 설치합니다. 처음 설치할 때 Android가 출처를 확인하도록 안내할 수 있습니다.

## 현재 포함된 프로토타입
- 강준영(초1), 강채영(초4) 선택
- 수학 10문제 + 국어 10문제, 20문제 혼합 출제
- 10분 타이머, 하트 3개, 5점씩 채점
- 아이별 날짜 기반 문제 순서, 당일 이벤트 추첨 결과 저장
- 아이별 아빠 서명 횟수 저장 및 서명 패드
- 기본 시스템 효과음 및 소리 켜기/끄기

## 꼭 알아둘 점
- 이 파일은 Android Studio에서 APK로 빌드할 수 있는 **초기 프로토타입 프로젝트**입니다. 이 환경에서 서명된 APK 자체를 빌드한 것은 아닙니다.
- 문제은행은 데모용 예시입니다. 실제 초등 교육과정에 맞춘 풍부한 문제은행, 모든 문제의 날짜 간 중복 방지, 서명 이미지 저장, 학습기록/보호자 잠금, 배경음악과 전용 효과음은 다음 개발 단계에서 보강해야 합니다.
- 현재 깜짝 이벤트는 아이별 하루 1회, 20% 확률로 추첨합니다.
